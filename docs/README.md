# docs

Method write-ups, data sources and disclosures, copied unmodified from the research repository at the end of the project. They
refer to file locations of that repository (`results/...`, `work/...`, `scripts/S*_...`, `bench_repo/`), many of which are not
part of this minimal repository.

- `DATA.md`: sources, versions, checksums and licences of every dataset.
- `DISCLOSURES.md`: protocol deviations disclosed by the agents. `VERIFICATION.md`: independent re-computation of key numbers.
- `core_v0.md` (S2 scoring and S3 merge, incl. presets in 7.9-7.14), `S0_families.md`, `S1_speciestree.md`, `S5_synteny.md`,
  `qfo_run.md`, `simulator.md`.
